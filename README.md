## 💡 Example Solution Format

I aim to keep solutions readable and, where useful, document the approach and time/space complexity.

```python
# Problem: Two Sum
# Approach: Hash map
# Time: O(n) | Space: O(n)

def twoSum(nums, target):
    seen = {}

    for index, number in enumerate(nums):
        complement = target - number

        if complement in seen:
            return [seen[complement], index]

        seen[number] = index

    return []
```
